客户端-服务器通信基本原理

TCP客户端-服务器通信

一个简单的客户端-服务器连接回显的编程

服务端代码

导入socket模块

import socket

创建一个 IPv4（AF_INET）的 TCP（SOCK_STREAM）套接字对象，命名为 sock。这个套接字将用于监听客户端的连接请求。

sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

定义服务器地址，IP 为本地回环地址 127.0.0.1，端口号为 10000。这表示服务器只监听本机的连接 

server_address = ('127.0.0.1', 10000)

将套接字绑定到指定的地址和端口。只有绑定了地址，客户端才能找到并连接它。

sock.bind(server_address)

使服务器进入监听状态，参数 1 表示最大等待连接的队列长度为 1（即允许一个连接在排队，多余连接将被拒绝）。此时套接字变为监听套接字

sock.listen(1)

阻塞等待，直到有客户端连接进来。当连接建立时，返回一个新的套接字 connection 用于和该客户端通信，以及客户端的地址 client_address（格式为 (ip, port)）。

connection, client_address = sock.accept()

通过 connection 套接字接收客户端发送的数据，最多接收 1024 字节。返回接收到的字节串

data = connection.recv(1024)

将收到的数据原样发回到客户端

connection.send(data)

关闭与客户端的连接

connection.close()

关闭对于套接字的监听

sock.close()

客户端代码

导入包

import socket

创建一个IPV4的套接字用于和服务器通信

sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

指定服务器的地址和端口

server_address = ('127.0.0.1', 10000)

主动连接服务器

sock.connect(server_address)

准备要发送的数据，必须是字节串（bytes 类型）。这里使用 b 前缀表示字节串。

messages = b'this is a message'

将数据发送到连接的套接字

sock.send(messages)

接收服务器的回显数据，最多 1024 字节

data = sock.recv(1024)

打印接收的数据

print(data)

关闭客户端套接字结束通信

sock.close()

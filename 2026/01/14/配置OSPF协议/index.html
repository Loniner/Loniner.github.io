配置OSPF协议

发表于2026-01-14|更新于2026-01-15|H3CIE学习
|总字数:1k|阅读时长:4分钟|浏览量:

OSPF协议是一种动态路由协议，可以动态的根据路由表中的信息来计算最佳路由，计算最短路径的指标一般是宽带

实验一

对于路由器<1>
首先设施loopback口，并为其设置ip 地址

int LoopBack 0

ip address 1.1.1.1 32

首先设置router ID 用来区分不同的路由器

router id 1.1.1.1

创建并进入OSPF进程1的配置视图，其中的“1”是进程号 

ospf 1

设置，并进入0区域，在OSPF协议中区域与所有区域相连，是中心区域。

area 0.0.0.0

设置路由器的回环接口，将IP为1.1.1.1的接口启用OSPF，并通告1.1.1.1/32的主机路由到OSPF区域0。告诉OSPF哪些接口需要参与OSPF协议，以及这些接口所在的网络属于哪个区域。

network 1.1.1.1 0.0.0.0

匹配10.0.0.0.0/24这个网段，匹配10.0.0.0到10.0.0.255的所有IP地址

network 10.0.0.0 0.0.0.255

匹配20.0.0.0/24整个网段

network 20.0.0.0 0.0.0.255

对于路由器<2>

首先设施loopback口，并为其设置ip 地址

int LoopBack 0

ip address 2.2.2.2 32

首先设置router ID 用来区分不同的路由器

router id 2.2.2.2

创建并进入OSPF进程1的配置视图，其中的“1”是进程号 

ospf 1

设置，并进入0区域（因为有了0区域此处也可以设置其他的）

area 0.0.0.0

设置路由器的回环接口。

network 2.2.2.2 0.0.0.0

匹配10.0.0.0.0/24这个网段，匹配10.0.0.0到10.0.0.255的所有IP地址

network 10.1.0.0 0.0.0.255

匹配20.0.0.0/24整个网段

network 20.0.0.0 0.0.0.255

之后两台主机便可以相互连接

实验二

对于交换机<1>

在loopback接口上配置ip 并将其设置为router ID

进入LoopBack 0接口

int LoopBack 0

ip address 1.1.1.1 32

qu

设置router ID
router id 1.1.1.1

设置ospf组编号,此处编号为<1>

ospf 1

进入0.0.0.0区域

area 0.0.0.0

在OSPF区域中宣告网络，将接口IP地址/网络段宣告到OSPF进程的指定区域中

network 1.1.1.1 0.0.0.0

将匹配20.0.0.0/24和10.0.0.0/24网段的接口启用OSPF，并把这些接口放入区域0.0.0.0中。

network 10.0.0.0 0.0.0.255

network 20.0.0.0 0.0.0.255

qu

对于交换机<2>

int LoopBack 0

ip address 2.2.2.2 32

qu

router id 2.2.2.2

ospf 1

area 0.0.0.0

network 2.2.2.2 0.0.0.0

network 10.0.0.0 0.0.0.255

network 20.0.0.0 0.0.0.255

qu

配置成功后ospf进程启动->进入邻居发现与建立->路由交换和计算->网络可达

使用一些命令查看路由表

显示OSPF协议进程计算出的路由表，即OSPF路由表

display ospf routing

显示设备的全局IP路由表，即实际用于转发数据包的路由表。

display ip routing-table

实验三

对于路由器<1> 连接10.0.0.0和20.0.0.0网络

int LoopBack 0

ip address 1.1.1.1 32

qu

ospf 1

area 0.0.0.0

network 1.1.1.1 0.0.0.0

network 10.0.0.0 0.0.0.255

network 20.0.0.0 0.0.0.255

设置router ID

router id 1.1.1.1

对于路由器<2>连接20.0.0.0和30.0.0.0网络

int LoopBack 0

ip address 2.2.2.2 32

qu

router id 2.2.2.2

ospf 1

area 0.0.0.0

network 2.2.2.2 0.0.0.0

network 20.0.0.0 0.0.0.255

network 30.0.0.0 0.0.0.255

对于路由器<3> 连接10.1.0.0和20.0.0.0网络

int LoopBack 0

ip address 3.3.3.3 32

qu

router id 3.3.3.3

ospf 1

area 0.0.0.0

network 2.2.2.2 0.0.0.0

network 10.1.0.0 0.0.0.255

network 30.0.0.0 0.0.0.255
